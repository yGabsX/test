# Tutorial completo (rápido) para publicar no Netlify Drop

Este projeto já está pronto para ser publicado como site estático.

## 1) Baixar os arquivos
- Se você recebeu uma pasta, deixe nela pelo menos o arquivo `index.html`.
- Opcionalmente compacte a pasta em `.zip` para facilitar no celular.

## 2) Publicar pelo Netlify Drop (PC)
1. Abra: https://app.netlify.com/drop
2. Arraste a pasta do projeto (ou o `.zip`) para a área de upload.
3. Aguarde o deploy terminar.
4. O Netlify vai gerar um link público (algo como `https://nome-aleatorio.netlify.app`).
5. Esse link já funciona para qualquer pessoa em Android, iPhone, PC e Smart TV com navegador.

## 3) Publicar pelo celular Android
1. Abra o Chrome no Android.
2. Entre em: https://app.netlify.com/drop
3. Toque em "Browse to upload".
4. Selecione o arquivo `.zip` do site (ou a pasta, dependendo do gerenciador de arquivos).
5. Aguarde o upload.
6. Copie o link gerado pelo Netlify e compartilhe.

## 4) Como trocar o link por um nome mais bonito (opcional)
1. Crie conta grátis no Netlify.
2. Vá no seu site publicado > **Site configuration** > **Domain management**.
3. Clique em **Options** para mudar o subdomínio (se disponível).

## 5) Atualizar o site depois
- Faça mudanças no `index.html`.
- Publique de novo no Netlify Drop (arrastando a pasta/zip atualizado).
- Você pode manter o mesmo site se usar conta e deploy conectado; no Drop simples pode gerar novo link.

## Observação importante
Eu não consigo gerar um link público definitivo daqui porque isso depende do upload na sua conta/dispositivo no Netlify. Mas o site está pronto para você publicar em menos de 1 minuto com os passos acima.
