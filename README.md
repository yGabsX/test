# TrilhaCerta

Site estático com duas abas principais:

1. **Análise de anúncio** de jipes, quadriciclos e motos de trilha com pontuação automática de custo-benefício.
2. **Anúncios recomendados** com links de busca no Facebook Marketplace.

## Rodar localmente

```bash
python3 -m http.server 4173
```

Depois abra `http://localhost:4173`.
